# Compañeros

Suelta aquí el PNG con el mismo nombre. Fondo transparente, pies abajo, el mismo tamaño en los seis.

Cuerpo, de frente: `kael-down.png` `lirien-down.png` `bram-down.png` `perrin-down.png` `elen-down.png` `halon-down.png`

De lado, mirando a la izquierda: el mismo nombre con `-left`.

De espaldas: el mismo nombre con `-up`.

Retrato del campamento: `por-kael.png` y así con los otros cinco.

Si el nombre no coincide, el juego no lo usa. Subir el archivo no cambia la página hasta que se empaqueta de nuevo.
